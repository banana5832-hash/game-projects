# Tripo로 게임용 .glb 만들기

그림 한 장을 Tripo AI에 올려 3D 모델을 만들고, 브라우저 게임(three.js)이 불러올 수 있는 크기로 맞춰 내려받는다.

## 먼저 확인할 것

1. **API 키**: 환경 변수 `TRIPO_API_KEY`가 있어야 한다. 키는 파일이나 채팅에 적지 않는다. 없으면 사용자에게 tripo3d.ai에서 키를 발급받아 환경 변수로 설정해 달라고 안내하고 멈춘다. 키가 없는 채로 생성을 시도하지 않는다.
2. **SDK**: `pip install tripo3d`가 되어 있어야 한다. 없으면 설치한다.
3. **잔액**: `python scripts/tripo_glb.py --balance`로 크레딧을 먼저 본다. 생성은 크레딧을 쓰고, 실패해도 일부가 빠질 수 있어서 한 번에 한 장씩 돌린다.
4. **그림 선택**: 정면을 보고 서 있고, 팔다리가 몸에서 떨어져 있고, 배경이 단순한 전신 그림이 가장 잘 나온다. 상반신만 있는 그림은 전신 모델이 되지 않는다. 사용자가 상반신 그림을 주면 결과가 반쪽이 될 수 있다고 먼저 말한다.

## 만드는 순서

1. 그림 파일 경로를 확인한다(jpg, png, webp).
2. 스크립트를 돌린다.
   ```bash
   python scripts/tripo_glb.py 그림.png --out output --face-limit 20000
   ```
   - 모바일까지 생각하면 `--lowpoly --face-limit 8000`을 쓴다. 저폴리 변환이 한 번 더 돌아서 시간과 크레딧이 더 든다.
   - 텍스처가 필요 없으면 `--no-texture`로 파일을 크게 줄일 수 있다.
3. 스크립트가 끝나면 출력된 파일 경로와 크기(MB)를 사용자에게 알린다.
4. 크기가 `--max-mb`(기본 15)를 넘으면 스크립트가 경고한다. 이때는 `--lowpoly`로 다시 만들거나 face-limit을 줄이자고 제안한다. 게임 아티팩트는 파일 하나당 15MB 이하여야 올라간다.

## three.js에 올릴 때 알아둘 것

- 파일은 `GLTFLoader`로 불러온다. 뼈대(리깅)가 없으면 걷는 동작 없이 통째로 움직인다. 걷기 동작이 필요하면 Tripo의 `rig`와 동작 기능을 따로 쓴다.
- 모델 크기와 방향은 그림마다 다르다. 불러온 뒤 바운딩 박스로 키를 맞추고, 앞을 보는 방향을 한 번 확인한다.
- 모델 하나가 수십 MB이면 휴대폰에서 느리다. 동료를 여러 명 쓰는 게임이면 한 명당 5MB 안팎을 목표로 한다.

## 주의

- 결과물은 사용자 그림에서 나온 것이므로, 친구끼리 하는 비상업 게임이라는 사용 범위를 넘어 배포하지 않는다. 그림의 출처가 불분명하면 사용자에게 물어본다.
- 성적인 묘사가 강조된 그림은 모델로 만들지 않고 다른 그림을 부탁한다. 교복 차림 인물은 연애 대상으로 쓰지 않는다는 프로젝트 규칙도 따른다.
- 실패하면 `task.error_msg`를 그대로 사용자에게 보여 준다. 같은 그림으로 계속 재시도하지 말고, 원인(해상도, 배경, 크레딧)을 먼저 짚는다.
